# HTML Web Development Lab & Experiments

Welcome to my repository! This project serves as a structured collection of my web development practices, focusing on core HTML5 components, structural layouts, and media integration.

## 📁 Repository Structure & Highlights

*   **`experiments/`**: A dedicated folder containing structured lab activities (`experiment_1.html` through `experiment_5.html`) along with a dedicated `index.html` landing page for these lab tasks.
*   **Media Components**:  ('practiced from FreecodeCamp')
    *   `HTML audio player.html` - Audio element implementation.
    *   `HTML video player.html` - Video element implementation.
    *   `HTML audio and video player.html` - Combined multimedia interface.
    *   `iframe video and map display.html` -iframe implementation.
*   **Webpage Layouts & Projects**: ('practiced from FreecodeCamp')
    *   `Traveling_Page.html` - A travel-themed landing page.
    *   `XYZ BookStore.html` - A e-commerce/bookstore layout prototype.
    *   `catphoto.html` - A basic structured practice page focusing on images and text content.
    *   `redheart.html` - An HTML component experiment.

## 🚀 Key Learning Objectives
*   Mastering foundational **HTML5 semantic elements**.
*   Integrating native **audio and video players** without external plugins.
*   Building functional structural components like forms, text formatting, and image handling.
